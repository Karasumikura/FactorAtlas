# 新算子扩展 —— 检验记录

2026-10-15。为覆盖 A股 尚未探索的因子族，新增 3 个算子（总数 40 → 43）：

| 算子 | 含义 | 理论依据 |
|---|---|---|
| `close_to_high` | 收盘 / n日最高价（接近阶段高点程度） | 突破/强势动量 |
| `volume_price_corr` | 价格变化与成交量变化的滚动相关 | 量价配合（健康量价 vs 背离） |
| `downside_days` | n日内下跌天数占比 | 下跌频率（区别于波动率） |

## 单因子检验（沪深300，hold=1，含成本）

| 因子 | OOS_Sh | 净Sh | 换手 |
|---|---|---|---|
| close_to_high_20_d-1 | **+0.46** | -0.03 | 0.49 |
| close_to_high_60_d-1 | +0.24 | +0.11 | 0.32 |
| close_to_high_120_d-1 | +0.08 | +0.11 | 0.23 |
| volume_price_corr_10_d1 | +0.42 | -1.21 | 0.44 |
| volume_price_corr_60_d-1 | -0.41 | +0.25 | 0.16 |
| downside_days_20_d-1 | +0.38 | -0.67 | 0.42 |

## 结论（诚实）

1. **三个新算子单独看都不够强**：要么 OOS 弱，要么被交易成本吃掉。
2. **`close_to_high` 有 OOS 信号（+0.46）但成本吃掉（净 -0.03）**，换手 0.49 太高。
   → 与 hold_sweep 结论一致：**A股 信号需降频才可交易**。它可能在 hold=5~20 下转正。
3. **不放宽标准**：新算子进不进最终幸存池，由完整挖掘的 BH-FDR 决定，
   不因"我们新加了算子"而降低门槛。

## 降频检验（假设验证 → 确认）

对 `close_to_high`（方向 d=-1，即"远离阶段高点"）做持有期 1/5/10/20 的净收益检验
（沪深300，成本 20bp）：

| 持有期 | cth_20_d-1 | cth_60_d-1 |
|---|---|---|
| h=1 | -41.6% / -2.16 | -28.4% / -1.25 |
| h=5 | -2.3% / -0.17 | -0.3% / +0.03 |
| h=10 | +2.8% / +0.41 | +3.8% / +0.52 |
| **h=20** | **+8.3% / +1.59** | **+8.9% / +1.69** |

**完美复现 hold_sweep 的核心结论：日频被成本碾碎，降频到 20 日后转正且 Sharpe 达 +1.6。**

**方法论启示：**
- 新算子（及所有 A股 因子）不能只看日频口径 —— 日频负不代表无效，可能是换手太高
- **A股因子挖掘必须配降频检验**：同一信号在 h=20 时可能是 Sharpe 1.6 的好策略
- 建议把"最优持有期净值"纳入常规评估，而非只报日频 Sharpe
