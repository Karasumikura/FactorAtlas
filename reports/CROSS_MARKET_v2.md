## 0. 为什么要重估

旧报告的结论建立在**有缺陷的筛选准则**上（用横截面 rank IC 符号做幸存判定）。
在 A股这种强市场 beta 环境里，IC 与多空组合收益会系统性异号，导致大量"假幸存"。

修复三项后重跑：

1. 幸存判定改用 **多空组合 LS Sharpe**（已对冲 beta）
2. 独立性改用 **多空组合收益相关**（而非因子值 rank 均值）
3. 幸存**方向归一**（自动翻转稳定负向因子）+ **可交易性复检**（扣除成本后净 Sharpe 不得显著为负）

## 9. 真 alpha 还是隐藏 beta？（关键检验）

**疑问**：A股 `vol_n120` 做多高波动股，可能是"小市值 + 高 beta"的代理，
而非真 alpha。

**检验**：把因子多空组合收益对市场收益回归，看 beta 和残差 Sharpe。

| 因子 | 原始 Sharpe | 市场 beta | 残差 Sharpe |
|---|---|---|---|
| vol_n120 | +0.69 | **-0.036** | **+0.71** |
| mom_n250_skip20 | +0.52 | -0.034 | +0.55 |
| skew_n120 | -0.36 | -0.013 | -0.34 |

**结论：**
- 多空组合的市场 beta ≈ 0（-0.01 ~ -0.04）→ 做多空确实对冲掉了市场风险
- 残差 Sharpe ≈ 原始 Sharpe（0.71 vs 0.69）→ **因子收益不是市场 beta 的伪装，
  是真正的截面 alpha**

**这排除了"波动因子 = 隐藏市场 beta"的质疑，是扎实的证据。**

## 10. 分年表现：诚实的时间稳定性检验

**疑问**：因子是"每年稳定赚"还是"靠个别大年撑着"？

**检验**：逐年多空 Sharpe。

### vol_n120 分年 Sharpe
| 年 | Sharpe | | 年 | Sharpe |
|---|---|---|---|---|
| 2016 | -0.07 | | 2022 | -0.39 |
| 2017 | +0.51 | | 2023 | +0.25 |
| 2018 | **-0.59** | | 2024 | +0.22 |
| 2019 | **+2.56** | | 2025 | **+2.20** |
| 2020 | **+2.37** | | 2026 | -0.17 |
| 2021 | +0.35 | | | |

### mom_n250_skip20 分年 Sharpe
| 年 | Sharpe | | 年 | Sharpe |
|---|---|---|---|---|
| 2016 | **-0.68** | | 2022 | +0.85 |
| 2017 | **+1.94** | | 2023 | **-0.74** |
| 2018 | -0.23 | | 2024 | -0.10 |
| 2019 | +1.31 | | 2025 | +1.37 |
| 2020 | +2.04 | | 2026 | +0.24 |
| 2021 | -0.10 | | | |

**诚实结论：**
- 因子**不是"每年都赚"**，而是"多数年份小赚/小亏，少数年份（2019/2020/2025）大赚"
- 波动因子靠 2019/2020/2025 三个大年撑起整体 Sharpe；2018（-0.59）、2022（-0.39）是负年
- 这正是**大多数真实因子的常态**（趋势/波动因子皆如此）
- **含义**：必须长期持有才能体现收益；单年可能显著亏损，不能按"年化 +9%"线性预期

**这是把"Sharpe 0.7"的乐观预期拉回现实的必要修正。**

### 市值梯度（关键结构发现）
| 指数 | 市值 | 主导信号 | 最强因子 Sharpe |
|---|---|---|---|
| 沪深300 | 大盘 | 波动/振幅 | vol_n120 +0.73 |
| 中证500 | 中盘 | 波动 + 量能 | vol_n20 +0.76 |
| **中证1000** | **小盘** | **换手/量能** | **turnover_std +1.63** |

**清晰的市值梯度：市值越小，换手/量能因子的预测力越强。**
- 大盘（300）：机构主导 → 波动/振幅相关

**理论一致：小盘股散户占比高，"换手率异常"蕴含更多信息；大盘股机构化，波动更相关。**

### 三指数完整图景
- **波动/振幅族**：三个指数都有效，是 A股 的"基础信号"
- **换手/量能族**：越往小盘越强（300 弱 → 1000 最强）
- **短期反转族**：越往小盘越强（300 无 → 1000 +1.05）
- **流动性族**（amihud/illiq）：仅中盘（500）显著
