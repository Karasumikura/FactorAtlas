# A股挖掘的 IC/LS 符号矛盾 —— 根因与修复

## 问题
修复前：A股 300 候选出现 **77 个"幸存"**，但它们的 `oos_ls_sharpe` **全为负（-0.67 ~ -0.74）**，
同时 `ic_mean` 与 `oos_ic_mean` 都为正。IC 与组合收益系统性矛盾。

## 根因（已用实测确认）
以 `hl_range_n20`（direction=1）为例，实测分层：

| 分层 | 平均次日收益 |
|---|---|
| Q1（波动最低） | +3.12 bp |
| Q2 | +4.03 bp |
| Q3 | +5.54 bp |
| Q4 | +6.60 bp |
| Q5（波动最高） | +11.22 bp |

- **分层完全单调递增**：多空组合 long Q5 − short Q1 = **+8.1 bp/日（LS 为正，正确）**
- **但全样本 rank IC = -0.0249（负）**

原因：A股存在**强市场 beta**——几乎所有股票次日收益均值为正。横截面 rank IC 比较的是
"因子秩"与"收益秩"，当低波动股涨得相对稳时，rank 相关为负；而多空组合**对冲掉 beta 后**
显示真实的正收益。

**结论：A股（及任何强 beta 市场）中，横截面 rank IC 与多空组合收益会系统性异号。用 IC 符号做
幸存筛选，会选中"IC 正但 LS 收益负"的假幸存。**

## 为什么 77 个假幸存全是负 Sharpe
候选对每个算子同时生成 `direction=1` 与 `direction=-1`。
- d-1 把因子翻成 `-hl_range`：Q5=波动最低 → LS = long(低波) − short(高波) = **-8.1 bp（负）**
- 但 IC 被翻成 **正** → 旧准则（IC 同号）选中了它
- 结果：所有 A股"幸存"都是 IC 正 / LS 负的假信号

## 修复（core/mine.py）
幸存判定从【IC 符号】改为【多空组合收益（已对冲 beta）】：
- 样本内 `ls_sharpe` 与 `oos_ls_sharpe` **同号**
- `|oos_ls_sharpe| >= 0.3`（幅度门槛）
- `net_ls_sharpe`（扣成本）方向不与 OOS 相反
- OOS IC 一致性降级为副证（`ic_consistent`），不再作为唯一依据
- 去重按 LS Sharpe 取更正的一份

## 修复 #2：独立性度量的错误（core/independence.py）
原 `independence` 用【因子值 rank 均值】算相关性，**高估相关性**：
A股里方向相反的两个因子（如高波动 vs 高换手）底层暴露相同，rank 均值也高度相关，
被误判成同族。

修复：新增 `ls_return_ts()`，改用【多空组合日收益】算相关（已对冲 beta）。

### 效果对比（28 幸存，000300）
| 度量基础 | 独立族数 | 是否正确 |
|---|---|---|
| 因子值 rank 均值（旧） | **1 族** | ❌ 把负相关的也算同族 |
| 多空组合收益（新） | **11 族** | ✅ |

但换手/量比/跳空/超买等反向族彼此独立，组合价值高。

## 修复 #3：幸存方向归一 + 可交易性复检（core/mine.py）
问题：幸存判定只要求"样本内与 OOS 的 LS Sharpe 同号"，不要求方向为正。
结果 `-1.80` 的反向信号也被列为幸存，方向是反的；报告里正负混杂。

修复（在幸存判定后追加两步）：
1. **方向归一**：样本内、OOS 的 LS Sharpe 都为负且净 Sharpe 亦为负 → 自动翻转 direction，
   重算所有指标，名字加 `_flip` 标记。使所有幸存都是"正向可交易"。
2. **可交易性复检**：翻转后 `net_ls_sharpe < -0.1`（扣成本后仍显著亏）→ 从幸存中剔除。

### 三项修复的累积效果（000905 中证500）
| 阶段 | 幸存数 | 质量 |
|---|---|---|
| 修复前（IC 准则） | 45 | 正负混杂，含净负假幸存 |
| 修复后（LS 准则 + 翻转 + 复检） | **23** | **全部正 OOS_Sh、全部可交易** |
